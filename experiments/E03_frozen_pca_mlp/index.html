    E03 · Frozen GeoFMs + PCA + MLP head¶

    Exactly the E02 input (12 months → PCA 128) with a trained MLP head instead of the classical classifiers: E02 → E03 isolates the effect of the head.

    Question¶

    Does a trainable neural head get more out of the same PCA input than logistic regression, random forest and SVM?

    Why¶

    GeoFM benchmarks evaluate frozen encoders with a trained neural head. E03 gives every input the same small MLP on exactly the E02 input, so a difference between E02 and E03 comes from the head alone. E03 is also the reference for E04: E03 → E04 changes only how the months are combined (PCA → L-TAE), with the same MLP head.

    What changes¶

    E02 E03
    Input 12 months concatenated → PCA 128 (baseline: 180 features) same
    Head LogReg, RF, SVM (grid on the validation fold) MLP 128 → 256 → 128 → 2, ReLU, batch normalisation, dropout 0.2
    Training – AdamW 1e-3, weight decay 1e-4, batch 128, class-weighted cross-entropy, ≤ 100 epochs, early stopping on validation macro-F1 (patience 15)
    Seeds 1 3 (mean ± SD)

    Inputs (all Sentinel-2 only): S2 baseline, Clay, Prithvi, TerraMind, AgriFM. Regions: Morocco and Utah 2023/24.

    Input¶

    Each parcel enters the MLP as one row of numbers, exactly the E02 input:

    Input Per parcel (file) Steps (fitted on the training folds of each round) Into the MLP
    S2 baseline 15 variables × 12 months = 180 (parcel_features_inner.csv) fill remaining gaps with the training median → standardise 180
    Clay v1.5 12 months × 1,024 = 12,288 (clay_agyear_tiles[_2023-24].npz) fill months without a clear pixel with the training median → concatenate → standardise → PCA 128
    Prithvi-EO-2.0 12 × 1,024 = 12,288 same 128
    TerraMind 12 × 768 = 9,216 same 128
    AgriFM 1 × 1,024 (one vector per year) same 128
    • Parcels: Morocco 8,775–8,781 and Utah 6,011–6,013 (the parcels common to all runs are scored).
    • Labels: irrigated (class 1) or rainfed (class 2).
    • No leakage: median, standardisation and PCA are computed on the 3 training folds only, then applied to the validation and test fold.

    Model¶

    flowchart LR X["input<br/>128 numbers<br/>(baseline: 180)"] --> H1["Linear → 256<br/>BatchNorm · ReLU<br/>Dropout 0.2"] H1 --> H2["Linear → 128<br/>BatchNorm · ReLU<br/>Dropout 0.2"] H2 --> O["Linear → 2<br/>softmax: P(irrigated), P(rainfed)"]
    Setting Value What it does
    Hidden layers 256 and 128 units (MLP: [256, 128]) learn non-linear combinations of the inputs
    Activation ReLU makes the network non-linear
    Batch normalisation after each hidden layer keeps training stable
    Dropout 0.2 (DROPOUT) switches off 20% of the units at random during training, against overfitting
    Output 2 units + softmax probability of each class; rainfed if P(rainfed) ≥ 0.5
    Trainable weights ≈ 67,000 (baseline input: ≈ 80,000) small compared with the ~1,200–5,000 training parcels × many epochs

    Training¶

    Setting Value (config ltae: section, script models_run/03c_train_ltae.py, HEAD: mlp)
    Optimiser AdamW, learning rate 0.001 (LEARNING_RATE), weight decay 0.0001 (WEIGHT_DECAY)
    Loss cross-entropy with class weights (rainfed errors count more, as rainfed is the minority class)
    Batch size 128 parcels (BATCH_SIZE)
    Epochs at most 100 (EPOCHS)
    Early stopping macro-F1 on the validation fold after every epoch; stop after 15 epochs without improvement (PATIENCE), keep the best epoch
    Seeds 3 per round: 42, 1042, 2042 (N_SEEDS); the out-of-fold prediction of a parcel is the mean probability of the 3 seeds
    Tuning none: the settings are fixed in advance, the validation fold only decides when to stop
    Validation PASTIS rotation: 3 folds train, the next fold validates, 1 fold tests; 5 rounds, so every parcel is predicted once
    Hardware GPU (one Slurm job per run)

    Label efficiency (part of this experiment)¶

    Every input is also trained on 10, 25 and 50% of the training blocks, so the report shows a learning curve next to the main result (Q5 of the experiment plan).

    Setting Value
    Fractions 10, 25, 50% of the training blocks of each round; 100% = the main run
    Sampling whole blocks: rainfed and irrigated-only blocks each put in a random order (per region, round and draw), and a fraction takes the first blocks of each list, so the draws are nested (10% ⊂ 25% ⊂ 50%); the order is accepted only if its first 10% hold ≥ 20 rainfed parcels. No fraction below 10%.
    Draws 3 per fraction; draw k is the same in E02–E05 and for every input (paired)
    Seeds 1 seed per draw (the main run keeps its 3 seeds)
    Validation and test folds unchanged
    Runs 5 inputs × 3 fractions × 3 draws = 45 per region, for the MLP head
    Result macro-F1 and rainfed F1 against the training fraction, one line per input, Morocco and Utah

    How to run¶

    # on the Mac (all regions, main and label-efficiency runs, compare, report):
#   experiments/run_experiment.py:  EXPERIMENT = "E03_frozen_pca_mlp"
python experiments/run_experiment.py
# on the cluster: one Slurm job per run, then one compare job per region (EXPERIMENT and DRY_RUN in the script)
python experiments/submit_slurm.py
    • Order: after E02 (compares with its runs: EXTRA_RUNS: "E02_frozen_pca/*").
    • Hardware: GPU (CPU works). QUICK = True checks the whole chain in a few minutes first.
    • Results: experiments/E03_frozen_pca_mlp/results/<region>/; the report page is written by the report step on the Mac.

    Outcome¶

    The MLP head is as good as E02's SVM for every input (all differences within ±0.01, none significant) and clearly better than LogReg and RF for most GeoFMs. A trained head therefore removes the weak-head problem, but it does not change the ranking of the inputs. Morocco: the S2 baseline with an MLP is the best result so far (0.908). Clay, Prithvi and TerraMind are 0.01–0.02 lower (not significant), and AgriFM is worse. Utah: Clay, Prithvi and TerraMind with an MLP beat the S2 baseline with an MLP by 0.04–0.05 (significant; +0.08–0.09 in Bear River). The S2 baseline's best head is still E02's random forest (0.764), so the best GeoFM (Clay + SVM, 0.791) leads by about 0.03. E03 also corrects E02: with an MLP, the S2 features find most of the rainfed parcels in Souss (84%), so the GeoFMs' advantage there was a head effect. Full tables, figures and interpretation are in the report.
