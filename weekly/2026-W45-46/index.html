    Weeks 2026-W45–46 · RQ1 complete in two regions¶

    In one line: frozen GeoFMs do not beat models trained only on our labels in Morocco (a tie at macro-F1 ≈ 0.91), but Clay is ahead by a small, significant margin in Utah (0.79 vs 0.76). Neither the classifier head nor the temporal aggregation changes this.

    1. Done this week¶

    • Utah added as a second, independent study area (WRLU 2024, agricultural year 2023/24; 2021 kept for a temporal test): the same pipeline as Morocco, with labels, spatial folds, tile store and model inputs → Utah training data, decision D13.
    • Sentinel-2 only for every input (foundation models and baselines), so that all inputs use the same optical data and both regions are treated alike → D14.
    • Embeddings of all four GeoFMs for both regions (Utah on the HPC cluster).
    • RQ1 experiment plan: four experiments, each changing one thing. Each runs in both regions, with label efficiency (10/25/50% of the training blocks × 3 draws) inside every experiment → experiment plan.
    • E02–E05 run on the cluster (Slurm, about 300 GPU/CPU jobs in total), copied back with checksums. Every experiment has a report with tables, figures, how-to-read notes and an interpretation:
      • E02 · PCA + LogReg / RF / SVM
      • E03 · PCA + MLP head
      • E04 · L-TAE temporal attention + MLP
      • E05 · PSE-TAE trained from scratch (neural baseline)

    2. Results¶

    Best macro-F1 of each input over all heads of E02–E05 (out-of-fold, 5 spatial folds, same parcels per region):

    Input Morocco Utah 2023/24
    S2 baseline (180 features) 0.908 (MLP) 0.764 (RF)
    PSE-TAE from scratch (S2 pixels) 0.911 0.755
    Clay v1.5 0.906 (L-TAE) 0.791 (SVM)
    Prithvi-EO-2.0 0.899 (SVM) 0.782 (SVM, L-TAE)
    TerraMind 0.899 (SVM) 0.785 (MLP)
    AgriFM 0.857 (MLP) 0.747 (MLP)

    • Morocco: a tie. PSE-TAE, S2 + MLP and Clay + L-TAE are all within ±0.01, and no difference is significant.
    • Utah: Clay is ahead. Clay + SVM beats PSE-TAE by +0.036 [+0.015, +0.056]. The gain is largest in Bear River, the main rainfed zone (+0.05 to +0.09).
    • The head matters only until it is non-linear. SVM, MLP and L-TAE give the same result for every input (within ±0.01). RF is weak on embeddings.
    • Temporal attention (L-TAE) adds nothing over concatenating the 12 months and reducing them with PCA.
    • Label efficiency: no advantage for the GeoFMs in Morocco. In Utah, Clay with 25% of the training blocks equals the S2 baseline with all blocks.
    • Correction of an early finding: E02 suggested that the GeoFMs work better in Souss. E03 showed that this was an effect of the classical heads: with an MLP, the S2 features find 84% of the rainfed parcels there.
    • AgriFM is the weakest input: it gives one embedding for the whole year, so the seasonal profile is lost.
